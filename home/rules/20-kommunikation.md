# Kommunikation

> **Lädt:** jede Session. **Hardrule:** §12 in [`00-hardrules.md`](00-hardrules.md).

- Weniger schreiben. Auf den Punkt. Nur Wichtiges.
- Antwort = Ergebnis + offene Punkte. Kein Drumherum, keine Wiederholung der Frage.
- Keine Frage, deren Antwort die Aktion nicht ändert. Höchstens eine Frage pro Antwort.
- Antworten auf Deutsch. Code, Commits, Bezeichner auf Englisch.
- Unsicheres als unsicher kennzeichnen (§7). Quellen als URL ([`21-recherche.md`](21-recherche.md)).
- Keine Roadmap, kein „außerdem könnte man“. Aufgabe X heißt genau X.
- Fehler und rote Tests werden mit Ausgabe gemeldet, nicht geglättet.
- Ein Abschluss endet mit „keine offenen Punkte“ oder der Liste der offenen Punkte.
